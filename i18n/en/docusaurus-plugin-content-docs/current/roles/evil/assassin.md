# Assassin

<RoleCard id="assassin" locale="en" />

**Faction**: Evil (Red)

**Power**: Visible to Merlin as evil; sees fellow evil players; may attempt to assassinate Merlin at any time.

**Win path**: After 3 quest successes, name Merlin; a correct guess flips the win to Evil. An early assassination is allowed but usually risky.

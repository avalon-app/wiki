# Recommended Roles by Player Count

Pick a **rule set** and a **player count** to see the recommended role line-up — matching [avalon-core](https://github.com/avalon-app/core)'s built-in configurations.

<RoleRecommendation locale="en" />

## Notes

- **Base rules** cover 5–10 players, sourced from the `variant: base` entries in [`data/role-combinations.yaml`](https://github.com/avalon-app/wiki/blob/main/data/role-combinations.yaml).
- **Lancelot expansion** covers 7–12 players (`variant: lancelot`). At **10 players** Evil has **no Assassin**; Morgana carries out the kill — see [Lancelot expansion](../rules/expansions/lancelot.md).
- For faction sizes and quest flow see [Rules Overview](../rules/overview.md).

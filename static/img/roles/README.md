# 角色卡图片

将每个角色的卡面图片以 `<role-id>.png` 命名放入本目录，例如：

- `merlin.png`
- `percival.png`
- `loyal-servant.png`
- `assassin.png`
- `morgana.png`
- `mordred.png`
- `oberon.png`
- `minion.png`

`role-id` 对应 `data/roles.yaml` 中的 `id` 字段（下划线请改为短横线，或两者保持一致并在 YAML 中调整）。

## 素材来源与许可

请仅使用：

1. 自绘 / 团队委托作品（注明作者、保留授权链）
2. 明确允许商用 / 非商用再分发的 CC 协议素材（注明出处与协议）

切勿直接复制官方桌游发行版的卡面以避免版权纠纷。

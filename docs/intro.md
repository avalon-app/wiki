# Avalon Wiki

「阿瓦隆」是一款隐藏身份的游戏。玩家要么是亚瑟王的忠诚仆人，代表正义和荣耀；要么是莫德雷德的追随者，站在邪恶一边。

- **善良阵营**通过成功完成三次任务获胜。
- **邪恶阵营**通过让三次任务失败获胜；此外也可以在游戏结束时刺杀梅林，或让任务无法继续进行，从而赢得胜利。

游戏中，玩家可以随时发表任何言论。**讨论、欺骗、指责和推理**都是善良战胜邪恶或邪恶掌控局势的关键。

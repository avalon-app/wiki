# 角色总览

阿瓦隆中的角色分属两大阵营。带 `*` 的角色仅在对应扩展启用时出现。

## 善良阵营（蓝方）

| 角色 | 速记 |
| --- | --- |
| [梅林](./good/merlin.md) | 看到除莫德雷德以外的全部坏人；和莫甘娜一起被派西维尔看到 |
| [派西维尔](./good/percival.md) | 看到梅林与莫甘娜，但分不清谁是谁 |
| [忠臣](./good/loyal-servant.md) | 无特殊信息，靠发言找坏人并保护梅林 |
| [兰斯洛特（好）](./good/lancelot.md)* | 与坏兰斯洛特同场，详见兰斯洛特扩展 |

## 邪恶阵营（红方）

| 角色 | 速记 |
| --- | --- |
| [刺客](./evil/assassin.md) | 任务成功 3 次后可刺杀梅林 |
| [莫甘娜](./evil/morgana.md) | 以梅林的样子被派西维尔看到 |
| [莫德雷德](./evil/mordred.md) | 梅林看不到他 |
| [奥伯伦](./evil/oberon.md) | 与其它坏人互相看不见 |
| [爪牙](./evil/minion.md) | 普通邪恶阵营成员 |
| [兰斯洛特（坏）](./evil/lancelot.md)* | 看不见自己队友，但被队友与梅林看见 |

完整角色元数据维护在 [`data/roles.yaml`](https://github.com/avalon-app/wiki/blob/main/data/roles.yaml)，构建后由 `@avalon-app/wiki/data/roles` 暴露。

# 兰斯洛特 · 邪恶阵营（Lancelot · Evil）

<RoleCard id="lancelot_evil" />

**阵营**：邪恶（红方，初始）

**能力**：

- 在游戏初始，「坏兰斯洛特」可以被「梅林」与其它坏人看到，但他**看不到其它坏人**。
- 在**规则 1 / 规则 2** 下，游戏过程中可能发生阵营转换：好坏兰斯洛特身份互换；其胜利条件按**游戏结束时**所属阵营判定。
- 在**规则 2** 下，处于坏人阵营时做任务只能出「任务失败」。
- 在**规则 3** 下不会发生阵营转换，可以与好兰斯洛特互相看见。

具体的阵营转换机制见 [兰斯洛特扩展](../../rules/expansions/lancelot.md)。

> 兰斯洛特的身份转换是玩家之间默默进行的，不会在角色查看中显示，相关投票限制也会对应生效。

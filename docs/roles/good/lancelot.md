# 兰斯洛特 · 善良阵营（Lancelot · Good）

<RoleCard id="lancelot_good" />

**阵营**：善良（蓝方，初始）

**能力**：与「坏兰斯洛特」一同出现在场上。

- 在**规则 1 / 规则 2** 下，游戏过程中可能发生阵营转换：好兰斯洛特与坏兰斯洛特的身份互换。
- 在**规则 3** 下不会发生阵营转换，但可以与坏兰斯洛特互相看见。

具体的阵营转换机制见 [兰斯洛特扩展](../../rules/expansions/lancelot.md)。

# 兰斯洛特（Lancelot）

## 背景

- 引入两名兰斯洛特：[兰斯洛特（好）](../../roles/good/lancelot.md) 与 [兰斯洛特（坏）](../../roles/evil/lancelot.md)。
- 游戏初始时，「坏兰斯洛特」可以被「梅林」和其他坏人看到，但**他自己看不到其他坏人**。
- 在游戏过程中（规则 1 / 2），兰斯洛特可能发生**阵营转换**：好人变坏、坏人变好。
- 「兰斯洛特」的胜利条件由**游戏结束时**所属阵营决定。

:::warning 特别提示
兰斯洛特身份转换是玩家之间**默默进行**的，不会在角色查看中显示，相关投票限制也会对应生效（如：规则 2 中，红方兰斯洛特只能投失败票）。
:::

## 规则 1

从第 3 个任务开始，每次队长组队前抽取一张「阵营转换卡」，可能发生 1 到 2 次「阵营转换」。

- 一共有 **5 张「阵营转换卡」**：3 张「空白」，2 张「阵营转换」。
- 如果抽取到「阵营转换」，则两个「兰斯洛特」的身份**互相对调**。
- 从第 3 个任务开始，**每次队长组队前**都抽取一张；一局游戏中有可能发生 1 次、2 次或 0 次转换。

## 规则 2

游戏开始时随机抽选 5 张「阵营转换卡」并亮出，每次任务开始时根据卡片判断兰斯洛特是否转变阵营；坏人阵营的兰斯洛特只能出「任务失败」。

- 共有 **7 张「阵营转换卡」**：5 张「空白」，2 张「阵营转换」。游戏最开始**随机抽选 5 张**全部亮出，按顺序对应到 5 次任务中。
- 每次任务开始时根据当前卡片判断兰斯洛特是否转变阵营。一局中可能发生 1、2 或 0 次转换。
- 在「兰斯洛特」处于坏人阵营时，做任务时**只能出任务失败**。

## 规则 3

「兰斯洛特」不会发生阵营转换，但好、坏阵营的「兰斯洛特」可以**互相看到对方**。

- 兰斯洛特不会发生阵营转换。
- 两位兰斯洛特互相可见。
